Insurance policy configuration

₹50,000 / year
Default game rule: 1.00% × ₹50,00,000 = ₹50,000 each year. This is a competition assumption, not an actuarially validated or real-world insurance quote.

Maturity settlement

At the end of the final published year, the simulation liquidates each team's holdings, clears outstanding premiums, applies the ₹50 lakh loan repayment and calculates any insurer payout within the cover limit.

Game settlement rule: if net portfolio assets are below the loan balance, the simulated insurer covers the shortfall up to the insured amount. Any remaining lender shortfall is reported. This is a fictional event mechanic, not a description of a real insurance policy.
